# Claims check

Search the draft for each pattern. Every hit must be fixed or backed by a fact the user confirmed.

| Look for | Why it's a problem | Fix |
|---|---|---|
| "$", "earn", "income", "profit", "passive", "side hustle" next to a promise | Income claim; many stores restrict these and buyers distrust them | Describe the task the product helps with instead |
| "guaranteed", "proven", "100%", "never fails" | Can't be backed | Say what was actually tested, e.g. "tested on our own launch" |
| "best", "ultimate", "#1", "the only" | Unprovable superlative | Use a specific feature instead |
| "limited", "only N left", "price goes up", countdowns | Fake scarcity unless it's literally true | Remove, or state the real date/limit the user set |
| Quotes, star ratings, "X happy customers" | Must be real and allowed to quote | Remove unless the user supplies the source |
| Numbers (pages, templates, minutes saved) | Must match the inventory | Recount from the files |
| Other brands in the title or as if official | Trademark / endorsement confusion | Move to "Works with ..." in Requirements |
| "AI-free", "hand-made", "100% human" | Only if literally true | Remove unless the user confirms it is |
| Text over ~4 lines without a break | Hard to read on a phone | Split or bullet |
| [ASK USER] still in text | Unfinished | List under Open questions |
