# Manual QA pass

Tick each line in the report under "Manual pass". Write "n/a" where it doesn't apply.

## Opening the files
- [ ] Unzipped on a clean folder: the top level has one obvious starting point (README or a single main file).
- [ ] Every PDF opens; page count matches the listing; fonts look right (no boxes or fallback fonts).
- [ ] Every spreadsheet opens; formulas show values, not errors (#REF!, #NAME?); sample data is fake, not someone's real data.
- [ ] Templates for other apps (Notion, Canva, Sheets): the share/duplicate link opens for a signed-out viewer.
- [ ] Images look sharp at 100% zoom.

## First five minutes as a buyer
- [ ] The README's first step works exactly as written.
- [ ] Nothing assumes knowledge the listing didn't mention under Requirements.
- [ ] There's a way to get help (store message, email) and it's stated once, clearly.

## Matches the listing
- [ ] Every item under "What's inside" is in the package, with the same count.
- [ ] Screenshots / cover show the real product, not a different version.
- [ ] Licence text matches what the listing says (personal / commercial / team).

## Leftovers
- [ ] No personal paths, emails, API keys, tokens or customer data inside files.
- [ ] No draft notes, TODOs, or "lorem ipsum" in buyer-facing text.
